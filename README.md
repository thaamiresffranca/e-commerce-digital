# 🚀 E-commerce de Produtos Digitais

Projeto desenvolvido como parte do desafio prático de Front-End, focado em criar uma loja virtual moderna de produtos digitais (cursos, e-books e templates).

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estrutura semântica)
* **CSS3** (Estilização, Variáveis CSS, Flexbox, Grid e Dark Mode)
* **JavaScript Puro (Vanilla JS)** (Manipulação do DOM, Array de produtos, Filtros em tempo real, Carrinho de compras e persistência com `localStorage`).

## 🎨 Funcionalidades
* Vitrine de produtos renderizada dinamicamente via JavaScript.
* Carrinho de compras funcional com cálculo de itens e salvamento no navegador (`localStorage`).
* Barra de pesquisa em tempo real por nome ou descrição.
* Filtros por categoria (Cursos, E-books, Templates).
* Alternância de Tema (Dark / Light Mode).
* Página de Checkout com validação de formulário.
* Layout responsivo para Desktop, Tablets e Celulares.

## 🚀 Como Executar o Projeto na sua Máquina
1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto no seu editor de código (como o **VS Code**).
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência (ou utilize a extensão *Live Server*).
